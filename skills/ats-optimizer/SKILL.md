# ATS Optimizer Skill

## Goal

Improve relevance and machine parsing without turning the resume into a keyword dump.

## Process

1. Extract the target role's important nouns and phrases from the job description: role title, product/domain terms, methods, systems, tools, and leadership expectations.
2. Map each keyword to verified evidence. Only add a keyword when the resume can support it.
3. Place important terms naturally in the headline, summary, skills, and relevant project bullets.
4. Prefer exact industry-standard wording when it is truthful, while keeping the prose readable.
5. Check that critical content is plain text and not dependent on icons, images, canvas elements, or CSS-generated text.

## ATS-friendly structure

Prefer recognizable headings such as:

- Professional Summary / Profile
- Skills
- Experience
- Projects
- Education
- Certifications (only when applicable)

Use semantic HTML and simple reading order. Avoid important information in multi-column constructs that become nonsensical when linearized.

## AI keyword families

When supported by evidence, consider terms such as:

- Generative AI / LLMs
- AI product strategy
- agentic workflows / AI agents
- prompt engineering / system prompts
- retrieval-augmented generation (RAG)
- embeddings / semantic search / vector search
- evaluation / evals / golden datasets
- structured extraction
- OCR / document intelligence
- human-in-the-loop
- AI guardrails / failure modes
- model orchestration
- inference latency / cost optimization
- AI observability

Do not add every term. Select the ones most relevant to the target job and evidence.

## Final ATS check

- Target title is obvious.
- Important job-description terms appear where justified.
- Skills are not repeated unnaturally.
- Dates and section names are parseable.
- Links contain useful text.
- No unsupported keyword was added only to game screening.
