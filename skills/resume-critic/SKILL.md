# Resume Critic Skill

## Goal

Run a final quality review from four perspectives: recruiter, hiring manager, ATS, and interview defensibility.

## Review passes

### 1. Recruiter scan

Assume 10–15 seconds. Can a reader immediately identify:

- the target role,
- the candidate's strongest differentiators,
- relevant domain/technical depth,
- two or three reasons to interview?

Flag weak opening sections, generic summaries, dense blocks, and buried impact.

### 2. Hiring manager review

Check whether the resume shows judgment, ownership, trade-offs, execution, cross-functional work, and outcomes. For AI/product roles, check that AI claims include enough technical/product detail to be credible.

### 3. ATS / parsing review

Check standard headings, plain-text availability, chronological clarity, keyword relevance, and whether the page still makes sense when read top-to-bottom without visual layout.

### 4. Defensibility review

For every metric, leadership verb, named technology, shipped-system claim, and AI capability ask: “What evidence supports this, and could the candidate explain it in detail in an interview?”

## Scoring rubric

Score each area from 1–5:

- Role alignment
- Evidence density
- Impact clarity
- AI/technical credibility
- ATS compatibility
- Scanability
- Writing quality
- Factual defensibility

A resume should not be considered finished if factual defensibility is below 5/5. Other categories should generally be 4/5 or better before publishing.

## Final output

Return:

1. Blocking issues
2. High-value improvements
3. Optional polish
4. Claims needing verification
5. Final scorecard

Fix blocking issues before publishing or generating the final PDF.
